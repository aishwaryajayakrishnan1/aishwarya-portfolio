# Aishwarya Jayakrishnan — Portfolio

## Site architecture

1. **Opening statement** — immediate role positioning and the central “chaos into clarity” promise.
2. **Career narrative** — explains the move from hands-on GenAI creative production into coordination.
3. **Anonymized case files** — three professional case studies focused on role, process and learning; no client names, proprietary assets or confidential metrics.
4. **Project approach** — an interactive five-step operating model.
5. **Brief simulator** — a small recruiter-facing interaction showing how Aishwarya responds to common project friction.
6. **Foundation** — education, business/technical background and relevant tools.
7. **Contact** — a clear invitation to discuss GenAI and digital project roles.

## Visual direction

The site treats project coordination as a creative operating system. Editorial typography and an off-white/black foundation keep it professional; acid lime, blue and coral behave like project notes, status signals and workshop artifacts. Motion is purposeful and reduced automatically for visitors who prefer less animation.

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

## Publish free with GitHub Pages

Upload the contents of this folder to a GitHub repository. In the repository’s **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and the root folder, then save.

Before publishing, replace or confirm the email address, and add Aishwarya’s real LinkedIn URL when available.

## Add creative gallery work

1. Copy approved images or videos into `assets/gallery/`.
2. Open `gallery-data.js` and copy the prepared example item.
3. Change the title, category, filename, alt text and description.
4. Save and refresh the page. The gallery and filters update automatically.
